# Type Specimen

Heading levels, inline styling, quotes, and footnotes — the typography surface. Back to the [index](./index.md).

## Second-level heading

A short paragraph. Enough to see how a single sentence sits on the baseline and how much space one line of body text occupies.

A longer paragraph, because measure and line-height cannot be judged on a single line. This one runs for several sentences so that the reading measure — the comfortable width a column of text settles at — becomes visible. When the article measure lands, this paragraph is where the eye either flows or stumbles: lines too long lose the return sweep, lines too short chop the rhythm into fragments. Punctuation hangs at the edge of lines, ==highlights== interrupt the grey of the text, and **bold** weights shift the colour of a line. If the type scale is right, this paragraph reads without effort at every viewport width from a phone to a 4K display.

### Sixth-level heading

The smallest heading, ~h6~, sitting directly under a paragraph — the tightest heading-to-body contrast on the page.

Inline styles in one line: **bold**, *italic*, ***bold italic***, ~~strikethrough~~, ==highlighted==, `inline code`, and a [link](./lists.md).
