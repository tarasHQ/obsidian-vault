# Markdown Test Suite

Iteration surface for the site's visual work — palette, typography, accents, and backgrounds are all judged against these pages, locally and on production. One page per family of constructs, so a single load is enough to judge a change:

- [Type specimen](./type.md) — heading levels, paragraphs, inline styling, blockquotes, footnotes
- [Lists & indentation](./lists.md) — ordered, unordered, task lists, deep nesting, heavy indentation
- [Code, tables & mermaid](./code.md) — syntax highlighting, wide tables, diagrams
- [Callouts & links](./links.md) — the full callout matrix, link variants, wikilinks, tags
- [Background sandbox](./bg.md) — sparse and tall; gradient and grain experiments live here

Supplements the older kitchen-sink page: [markdown-test](../../markdown-test.md).
